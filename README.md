## Core Patterns

- **Bilbo Simple To Complex**: The Bilbo Principle: always establish simple, known primitives before introducing complex distributed mechanics.
- **Practical Application**: Developer onboarding guides and API quickstarts.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
